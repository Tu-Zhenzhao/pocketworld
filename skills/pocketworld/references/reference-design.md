# From an idea to a design reference

If the user supplies only a scene sentence, use the host agent's image tool to establish a reference when available. If an image is already supplied, use it to understand the story, pose, palette and composition, then redesign details for the native grid. Avoid asking for another image when the agent can make progress itself.

The reference can be a large image. It is a design guide, not the final raster substrate: the agent subsequently authors native shapes and motion. Do not shrink/quantize the image and call that the native result. If image generation is unavailable, create an authored blockout still, explain the missing reference step, and continue within the user's scope.

## Prompt scaffold

Adapt this to the actual story; do not paste the juggler into every scene:

> A quiet pocket diorama of [subject and setting], with [specific supported pose] and [one clear primary action]. Square composition on pure white with generous margins; an orthographic three-quarter view near45° azimuth/30° elevation, adapted for readable overlaps. Deliberate pixel-like shape clusters, restrained natural palette and one coherent key light. [Species/character/prop identity cues]. [Named hand/foot/body contacts]. Leave the moving parts, grip and important negative spaces readable. Choose a footprint suited to [story]; no horizon or dense full-frame texture. No text or watermark.

Identify anatomy and framing defects in the reference before coding. Keep the useful direction, then simplify surfaces and deliberate tiny features at the actual cell budget. A reference's attractive texture does not prove that the pose, supports or animation can work.

For the buffalo study the reference helped separate forehead, short muzzle, folded legs, supported sleeping pose and raised knee. The final head angle, volumes, palette, breathing surface and animation were authored separately. For a new subject choose its own cues, contacts and composition.
