# Scene decisions

Replace this note with a short record of the actual design, not a checklist essay.

- Input: story/action that must survive; optional objects, texture or framing that can change.
- Viewed study/anchor: actual image path and the specific shape/spacing decision it informed.
- Identity: 3–5 silhouette cues and meaningful gaps; supports and contact relationships.
- Budget: actor, head, hand and essential prop dimensions in native cells; then choose canvas/framing. The starter grid is not a quality target.
- Still: save silhouette and major value groups before texture. Name the defect and structural fix.
- Motion: primary action, support response, quiet anchors, event causes; record extremes and neighboring times to inspect.
- Review: actual rendered evidence, remaining weaknesses, any justified budget change; user approval only if actually given.
